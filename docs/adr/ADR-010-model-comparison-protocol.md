# ADR-010: 모델 비교·선택 프로토콜 (동일 조건 원칙)

**상태:** 채택

---

## 맥락

"모델 A가 모델 B보다 낫다"는 주장은 비교 조건이 동일할 때만 유효하다.  
훈련 데이터 분할, 평가 지표, 운영점(임계값) 중 하나라도 다르면 수치 비교가 무의미해진다.  
초기 실험에서 RandomForest와 XGBoost를 서로 다른 임계값에서 비교한 결과를 그대로 문서화하는  
오류를 방지하기 위해 비교 프로토콜을 명시적으로 결정한다.

---

## 고려한 대안

### 대안 A: 조건 제약 없이 각 모델 최적 임계값 비교

- 각 모델이 자신에게 유리한 임계값에서 측정한 수치를 비교
- **배제 이유:** 임계값이 다르면 recall/precision 트레이드오프 자체가 다르다.  
  "XGBoost recall 0.85 vs RF recall 0.80"이 동일 임계값 기준인지 알 수 없으면 무의미.

### 대안 B: 헤드라인 지표(PR-AUC)만 비교 — 채택 (주요)

- PR-AUC는 전 임계값 범위의 면적이므로 임계값 선택에 독립적
- 동일 분할에서 PR-AUC만으로 1차 후보 선정
- **채택 이유:** 임계값 의존성을 제거하고 모델 자체 능력을 비교할 수 있음

### 대안 C: 동일 임계값(0.5)에서 전 지표 비교 — 채택 (보완)

- PR-AUC 이후 최종 확인 단계에서 동일 threshold=0.5 기준으로 recall/precision/F1 비교
- 운영점이 결정되면 해당 임계값으로 재비교

---

## 결정

다음 순서로 모델을 비교·선택한다:

1. **동일 조건 고정:** 데이터 분할(시간순 80/20, [ADR-002](ADR-002-time-based-split.md)), 전처리, 피처셋 동일. random_state=42는 모델 시드에만 적용
2. **1차 비교:** PR-AUC — 임계값 독립적 지표로 후보 순위 결정
3. **2차 비교:** threshold=0.5 기준 recall/precision/F1 — 운영 수준 차이 확인
4. **3차 기준:** 해석가능성 · 추론비용 · 재학습 용이성 — 수치 우위가 없을 때 결정 인자
5. **선택 기록:** 어떤 조건에서 어떤 이유로 선택했는지 이 프로토콜 형식으로 문서화

**현재 결정:** XGBoost (`scale_pos_weight=28.52`)  
선택 근거: PR-AUC 0.830 vs RF 0.783, +0.047 우위. 해석가능성·재학습 용이성은 동등.

---

## 이유 (인과)

비교 조건 통제가 없으면 "더 나은 모델"이 실제로는 "더 유리한 조건에서 측정된 모델"일 수 있다.  
이 프로토콜은 향후 LightGBM·CatBoost·신경망 등 추가 후보를 비교할 때도 동일하게 적용된다.

---

## 포기한 것 / 트레이드오프

각 모델에 최적화된 임계값을 적용하면 개별 성능을 더 높게 보여줄 수 있다.  
이 유연성을 포기하고 동일 조건을 강제함으로써 비교의 공정성을 확보한다.  
운영점이 결정된 이후에는 그 임계값에서의 비교로 프로토콜을 업데이트한다.
